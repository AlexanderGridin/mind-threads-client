# Adding vitest

## Goal

We need to add a Vitest for being able to write unit-tests in this application.

### High-level plan

1. Install a Vitests package in this project.
2. Configure it to work properly.
3. Update the App component within the @src/App.tsx file to have a button that toggles the visibility of the "MindThreads" text.
4. Add unit-tests for the updated App component component. These tests should be placed within the @src/__tests__/ folder. The file with tests should have the following extention `.test.ts(x)`.
5. Update the @CLAUDE.md file.
