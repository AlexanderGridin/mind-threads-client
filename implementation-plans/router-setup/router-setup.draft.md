# React router setup

## Goal

Based on the information within the file @.doc/react-router.md we need to install and setup browser router for our application.

### High-level plan

1. Read the @.doc/react-router.md file first. It has all necessary data that we need during the implementation of this feature.

2. Install react router.

3. Create 2 page components within the @src/pages/ folder (it needs to be created): HomePage and ThreadPage. Currently, it is enought for this components to render their names as h1 title.

4. Cover these new components with unit-tests.

4. Configure routing within the @src/routing/ folder (it needs to be created).

5. Integrate the routing configured with the App component within the @src/App.tsx file.

If you find any conserns, questions, or inconsistency, counter points, then discuss them with the developer first before creating the plan.
